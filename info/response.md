# Ответы

* Все ответы обернуты в основной ответ
* При успехе `data` не `null`
* При ошибке `error` не `null`
```json
{
  "error": null,
  "data": null
}
```

# Ошибки
* Сообщение `message` Описание ошибки
* Код `detail` тип ошибки
```json
{
    "error": {
        "message": "Access denied",
        "detail": "UnauthorizedException"
    },
    "data": null
}
```
