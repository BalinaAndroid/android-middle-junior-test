# Работа с файлами

* Файл без прикрепления может быть удален через 15 минут
* Для всех запросов требуется авторизация

#### Загрузка

* Отправить `POST` `multipart form data` `file/upload` с одним или более файлом.
* В качестве ответа будет выданы `id` загрузки

```json
{
  "list": [
    "01a1932e68e4799da5eb1092ef673d50",
    "01a1932e6911721fa211f5085b87bc64",
    "01a1932e69467a96a5ad0e9ebd9e5005"
  ]
}
```

### Информация о файле

* Отправить запрос `GET` `file/info/01a1932e6911721fa211f5085b87bc64`
* Ответом будет информация следующего формата

```json
{
  "name": "01a1932e6911721fa211f5085b87bc64",
  "size": 185292,
  "created_at": "2026-10-31T18:17:34.737831",
  "last_request": "2026-10-31T18:17:34.737859",
  "content_type": "image/png",
  "request_count": 0
}
```

### Получение файла

* Отправить `GET` `file/01a1932e6911721fa211f5085b87bc64`
* В качестве ответа будет передан массив байт файла.
